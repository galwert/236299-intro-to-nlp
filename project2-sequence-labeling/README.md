# NLP (236299), Project 2: Sequence labeling

Slot filling on ATIS flight queries as a sequence-labeling task in PyTorch:
from a hidden Markov model baseline through a BiLSTM tagger, with
token-level and span-level evaluation. `project2_sequence.pdf` is the
rendered submission.

```bash
pip install -r requirements.txt
jupyter notebook project2_sequence.ipynb
```
