# NLP (236299), Project 4: Semantic interpretation for question answering

Semantic parsing of ATIS flight questions into executable logical forms
(`grammar`), built on the CKY parser from project 3 and used to answer
questions against a flight database. `project4_semantics.pdf` is the rendered
submission.

```bash
pip install -r requirements.txt
jupyter notebook project4_semantics.ipynb
```
