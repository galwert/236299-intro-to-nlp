# NLP (236299), Project 3: CKY parsing

Constituency parsing of ATIS flight queries with the CKY algorithm, in a
PyTorch-era notebook: completing a context-free grammar for the ATIS domain
(`grammar`), CKY recognition, CKY parsing with tree reconstruction, and a
probabilistic (PCFG) variant that returns the most likely parse.
`project3_tree.pdf` is the rendered submission.

```bash
pip install -r requirements.txt
jupyter notebook project3_tree.ipynb
```
