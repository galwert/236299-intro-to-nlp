# NLP (236299), Project 1: Text classification

A PyTorch notebook that builds and compares text classifiers of increasing
capacity: a majority baseline, naive Bayes, logistic regression and a
multilayer perceptron, with bag-of-words features and evaluation on a held-out
set. `project1_classification.pdf` is the rendered submission.

```bash
pip install -r requirements.txt
jupyter notebook project1_classification.ipynb
```
